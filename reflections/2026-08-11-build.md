# Reflections — 2026-08-11 (build phase)

Learnings from building the initial tool and running the first review.

## Verified against real data
- Open-Meteo archive returned 5 years of hourly wind for Boulder in one request
  (~43.8k rows). Results are physically sensible: calmest early morning (04:00–09:00,
  ~6.5 km/h), windiest mid-afternoon (14:00–16:00) — textbook diurnal wind from daytime
  convective mixing. The by-month breakdown adds real value: winter (Jan/Feb) shifts the
  calm window to midday/evening rather than dawn.

## Environment gotchas
- macOS system Python 3.9 links LibreSSL, so urllib3 v2 prints a harmless
  `NotOpenSSLWarning` on import. Not fatal; ignore.
- pandas `freq="H"` warns (FutureWarning) on pandas 2.x but is kept for pandas 1.5
  compatibility — lowercase `"h"` isn't valid on older pandas.
- **Custom subagents register at session start.** Writing `.claude/agents/code-reviewer.md`
  mid-session did NOT make it spawnable by name (`agent type not found`). Ran the review
  via the general-purpose agent with the reviewer's criteria instead. The named agent will
  be available after a session reload/restart.

## Review findings applied (all 5)
- Moved fetch/cache status messages into `fetch_wind` (to stderr) so a cache hit no longer
  falsely prints "Fetching" — the print was in `main.py` ahead of the cache check.
- Snapped `default_date_range` to month boundaries so the cache key is stable within a
  month (was keyed on `today`, so it changed daily and never reused the download).
- `calmest_window` now raises if every candidate window contains a NaN (was returning a
  bogus `inf` window).
- Added tests for the midnight-wrap window and the all-windows-NaN case.
- Surfaced the computed `median_speed` in the report table (was computed but unused).

## Process note
- The "apply everything the reviewer suggests" rule ([[plans-reflections-convention]] lives
  in CLAUDE.md) worked cleanly here — all 5 were reasonable. None needed to be pushed back
  on. Re-ran tests + end-to-end after the fixes to confirm green.
